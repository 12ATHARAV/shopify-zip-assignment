Shopify Storefront Integration Steps

  1. Deploy the Backend API: Deploy this project to Railway. Copy your assigned public URL (e.g. https://shopify-zip-pricing-production.up.railway.app).
  2. Open Shopify Theme Code Editor: Log in to your Shopify Development Store. Go to Online Store > Themes. Click the ... icon next to your active theme and click Edit Code.
  3. Add the Liquid Block: Locate the file sections/main-product.liquid (or snippets/product-template.liquid). Find the code rendering the price: {{ product.price | money }}.
  4. Paste the Widget Code: Paste the custom widget liquid code (found inside shopify/zip-pricing-widget.liquid in this repo) right below the product price code. Update the BACKEND_API_URL constant in the script to match your Railway deployment URL.
  5. Save and Test: Open any product page on your store, type one of the test zip codes (e.g. 75028) and click Check Price to see the pricing update live!
